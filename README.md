# Trajectory Inpainting with a Temporal Convolutional Network

This repository contains the code for training and evaluating a Temporal Convolutional Network (TCN) that reconstructs missing (masked) segments of 2D trajectories. All experiments use synthetic data generated by the script itself.

## Overview

The script `TCN_synthetic_data_polished.py` does the following:

1. **Generates synthetic trajectories.** Each trajectory is a 2D curve of 200 time steps built from sinusoids with random phase shifts and additive Gaussian noise (`noise_std = 0.02`).
2. **Masks a contiguous gap.** For each trajectory, a single gap covering 20% of the sequence is hidden at a random position.
3. **Trains a TCN** to predict the full trajectory from the partially observed one.
4. **Evaluates** MSE, MAE and R² on the masked regions only. Each metric is computed per trajectory and then averaged, and the standard deviation across trajectories is reported.
5. **Plots** true vs. predicted trajectories and the reconstructed trajectories (observed values for the known part, predicted values for the masked part).

## Requirements

- Python 3.9+
- numpy
- torch
- matplotlib
- scikit-learn

Install with:

```bash
pip install numpy torch matplotlib scikit-learn
```

A GPU is used automatically if available; otherwise the code runs on CPU.

This generates the dataset, trains the model, prints the evaluation metrics (including a ready-to-paste table), and opens the visualization windows.
